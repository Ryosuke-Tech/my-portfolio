インフラエンジニア（ネットワーク・TV会議システム）

はじめまして、O.Rです。ネットワークの運用監視、TV会議システムの導入・構築、データベースの運用、NW機器の保守対応を経験してきました。

現場では、顧客との要件確認、現地調査、機器の設置と通信試験、完成図書の作成まで、一通りの工程を担当しました。サブリーダーとして、工程管理や下請けベンダの取りまとめも経験しています。最近は、HTML/CSS/JavaScriptで個人制作のWebアプリ（筋トレメモ）も作りました。

  • 大規模新築ビルの会議室に、TV会議端末を250台以上設置し、ZoomとGoogle Meetで通信試験
  • 医療系機構向けのTV会議・同時通訳システムを、サブリーダーとして工程管理（チーム20名）
  • 官公庁向けのTV会議システムを、サブリーダーとして構築（1年7ヶ月、チーム15名）
  • H3C無線機器の問い合わせ対応を、1日10〜20件担当
  • TOEIC 745点（2019年8月）

業務経歴

新しい案件から順に載せています。顧客名は伏せています。

  1. 2026年4月〜2026年9月（6ヶ月）

    NW機器保守対応（H3C無線機器）

    チーム7名 / 全体50名 ・ Windows、Comware V7

    H3Cの無線機器（Wi-Fi機器）に関する問い合わせに、1日10〜20件対応しました。障害の切り分け、設定変更、設置の案内、操作説明が対応範囲です。デモ機の貸し出しと管理、依頼に応じた無線機の設置・操作手順の勉強会の開催、Wi-Fiの電波が届く範囲を示すヒートマップの作成も担当しました。

  2. 2025年12月〜2026年3月（4ヶ月）

    大規模新築ビル会議室向けTV会議システムの設置

    チーム5名 / 全体10名 ・ Windows、Android

    TV会議端末を250台以上設置し、ZoomとGoogle Meetで通信試験を行いました。ビルの工事に関わる家具業者や施工業者と作業日程を調整し、端末、ディスプレイ、スタンドを搬入して各会議室に設置し、通信試験までを担当しました。

  3. 2025年1月〜2025年7月（7ヶ月）

    自治体向けITソリューションの運用

    チーム2名 / 全体15名 ・ SQL Server

    住民情報を管理するデータベースの運用と、それを使った給付金対応を担当しました。SQLをベースにしたデータベースの更新に加え、給付金施策のときは、データベース上で対象者を審査し、振り込み通知書を発行しました。作業後は、自治体の給付金担当者に、更新内容と作業結果を説明しました。SQLに関する簡易なQA対応も担当しました。

  4. 2023年5月〜2024年3月（11ヶ月）

    医療系機構向けTV会議・同時翻訳システムの構築

    サブリーダー ・ チーム20名 / 全体20名 ・ Windows、Android

    東京と関西の間で医薬系の相談を行うシステムです。Web会議も混ぜ、海外の顧客も参加するため、会議室に同時通訳システムを設置し、Webと会議室をつなぐハイブリッド会議を実現しました。全体の工程管理を担当し、下請けの開発ベンダの取りまとめと、プログラムの品質チェックも行いました。

    担当した作業と導入機器
    • 顧客との要件確認、現地調査、スケジュール管理、機器の発注
    • 導入前の動作確認（TV会議端末とオーディオ機器）と接続試験（TV会議どうし、TV会議とWebex）
    • 顧客・ベンダとの作業調整、現地作業資料（手順書、試験表、作業申請）の作成
    • 現地作業の立会い・指示、部材の搬入搬出、設定投入、通信試験、正常性の確認
    • 構築後のQA対応とベンダへのエスカレーション、完成図書（設計資料、マニュアル、試験表、コンフィグ等）の作成
    • Poly（旧）Group500
    • ClearOne 音声ミキサー
    • TAIDEN マイクユニット（言語切り替え用）
    • Panasonic レコーダー（会議音声録音用）

  5. 2022年1月〜2023年7月（1年7ヶ月）

    官公庁向けTV会議システムの設置・構築

    サブリーダー ・ チーム15名 / 全体20名 ・ Windows、Android

    本庁の会議室と各幹部の自宅にTV会議システムを設置し、リモートと会議室をつなぐ会議を実現しました。TV会議端末のキッティング、端末と多地点接続サーバーを組み合わせた統合試験、現地構築後の品質試験が主な業務です。導入後の2次問い合わせ（障害時のベンダ問い合わせと顧客への回答）も担当しました。

    担当した作業と導入機器
    • 顧客との要件確認、現地調査、スケジュール管理、機器の発注
    • 導入前の動作確認（TV会議端末）と接続試験（TV会議とサーバー）
    • 顧客・ベンダとの作業調整、現地作業資料の作成、現地作業の立会い・指示
    • 設定投入、通信試験、正常性の確認、構築後のQA対応とエスカレーション、完成図書の作成
    • Poly（旧）X30・X50・Group500
    • Poly（旧）多地点接続サーバー RMX
    • iPad Air

  6. 2018年8月〜2019年8月（1年1ヶ月）

    ネットワークの運用監視

    チーム8名 / 全体10名 ・ Windows

    Cisco製品を中心としたNW機器を、24時間365日で運用監視しました。定期的なPingの疎通確認、障害時のログ取得、原因の究明と復旧作業（一次切り分け、ベンダへのエスカレーション）、監視ツールZabbixでの状況監視とアラート発生時の原因調査を担当しました。英語圏のユーザーもいたため、英語でのメール・電話対応（メール9割、電話1割）も経験しました。
